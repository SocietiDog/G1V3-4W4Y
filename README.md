**A free, open-source Twitch Giveaway & Trivia bot for Guild Wars 2 streamers**

## 🎁 About
G1V3 - 4W4Y is a free, open-source WPF desktop application that brings giveaways and trivia to your Twitch streams. Built specifically for **Guild Wars 2** streamers, it offers:

- **Giveaway Management** — Random winner selection from chat, subscriber bonuses, followers-only mode
- **Trivia-Tron** — Interactive trivia with leaderboard and IQ rewards
- **Prize Bank** — Manage GW2 items, gold, and custom prizes with a visual overlay
- **Chat Integration** — Twitch chat detection, YouTube beta support
- **Overlay System** — Stream-ready countdown and prize display overlays
- **Local Data Storage** — All data stays on your PC; no cloud dependency

## 🚀 Quick Start
1. Download and run the `.msi` installer
2. Launch the app and connect to your Twitch channel
3. Configure your bot name and OAuth token
4. Set up prizes in the Prize Bank
5. Start giveaways or enable Trivia-Tron!

For detailed instructions, visit [g1v34w4y.wordpress.com](https://g1v34w4y.wordpress.com/)

## ✨ Features Highlights

### Giveaways
- Standard entry mode or GW2 account name entry
- Subscriber bonus entries
- Followers-only giveaways
- Visual overlay with countdown timer
- Chat history of winners

### Trivia-Tron
- Multiple-choice trivia rounds
- Leaderboard with IQ points
- Commands: `!trivia`, `!iq`, `!answer`, `!leaderboard`
- Answer aliases: `!a`, `!ik` (I Know), `!qr` (quick roll)

### Prize Bank
- Configurable grid layout
- GW2 item integration with icons
- Gold and custom prizes
- Roll animation with winner highlight
